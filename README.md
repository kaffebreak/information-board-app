# 防災・交通情報モニタ

事務所のモニタに常時表示するボードです。スクロールもクリックも使いません。
画面は2つあります。

| 画面 | アドレス | 内容 |
|---|---|---|
| 防災・交通情報 | `http://127.0.0.1:8765/` | 発令条件の判定、鉄道、伊勢湾岸道 |
| 風向・風速 | `http://127.0.0.1:8766/` | 名古屋港高潮防波堤と四日市防波堤信号所の観測 |

## 構成

| ファイル | 役割 |
|---|---|
| `bousai_board.py` | 防災・交通情報のサーバー。各機関からデータを集め、表示用ページとまとめたJSONを配信します |
| `bousai_board.html` | 防災・交通情報の画面（15秒ごとに自動更新） |
| `kaze_board.py` | 風向・風速のサーバー |
| `kaze_board.html` | 風向・風速の画面（15秒ごとに自動更新） |
| `config.json` | 表示路線、地図キー、画面の位置などの設定。APIキーを書くファイルなのでgitには含めません（`config.example.json` をコピーして作ります。無くても既定値で動きます） |
| `config.example.json` | `config.json` の見本 |
| `start_board.bat` | 有効なサーバーを起動し、応答したものからEdgeの全画面表示を開きます。サーバーが止まったときは10秒後に再起動します |
| `stop_boards.bat` | ボードのサーバー、自動再起動の監視、専用のEdge画面を終了します |
| `run_server.bat` | 防災・交通情報のサーバーだけを、画面を開かずに起動します（止まったら10秒後に再起動）。通常は使いません |
| `launch_boards.py` / `stop_boards.py` | 上のバッチから呼ばれる本体 |
| `board.log` / `kaze_board.log` | 各サーバーのログ（各1MB・バックアップ3世代）。Windowsでのローテーション競合を避けるため、ファイルは共有しません |
| `kaze_history.json` | 風配図用の観測履歴（24時間分。自動で作られます） |

## 準備（初回だけ）

1. Python 3.9 以上をインストールします。追加ライブラリは不要です。
2. このフォルダを表示用PCの任意の場所に置きます（例: `C:\bousai_board`）。
3. 設定を変える場合は、`config.example.json` を `config.json` にコピーして編集します。
4. `start_board.bat` をダブルクリックします。Edgeが全画面で開けば完了です。
   全画面を抜けるときは `Alt + F4` を押します。

`start_board.bat` は各サーバーが応答してから画面を開きます。各画面は独立して待つので、
片方の取得が遅れても、もう片方の画面は止まりません。Edgeのプロファイルは画面ごとに分けています。

表示の確認だけしたいときは、ブラウザで次のアドレスを開いてください。ダミーデータで表示し、実データや履歴には書き込みません。

- `http://127.0.0.1:8765/?demo=1`：警報が複数出て、路線が止まった状態
- `http://127.0.0.1:8766/?demo=normal`：弱風と通常値
- `http://127.0.0.1:8766/?demo=1`：弱風と、注意ライン以上の古い値を同時に表示
- `http://127.0.0.1:8766/?demo=high`：新しい観測が注意ライン以上の状態
- `http://127.0.0.1:8766/?demo=retry`：取得再試行中と、最新の観測が欠測の状態

## 起動時に自動で表示する

1. `Win + R` で `shell:startup` と入力し、スタートアップフォルダを開きます。
2. `start_board.bat` のショートカットをそのフォルダに置きます。

あわせて、Windowsの設定で「スリープ」「画面の電源を切る」を「なし」にしてください。
自動ログオンにしておくと、停電後の再起動からそのまま表示まで戻ります。

画面の位置（`bousai_window_position` / `wind_window_position`）が未設定だと、Windowsの既定の位置に開くため、
2つの画面が重なることがあります。モニタ番号から座標を推測せず、Windowsの画面配置で確認してください。
実機の3画面への配置は未検証です。

## 終了と設定の変更

終了するときは `stop_boards.bat` を実行します。防災・風向のサーバー、自動再起動の監視、
起動待ちのランチャー、専用のEdge画面を終了します。`enable_wind` が `false` でも、起動済みの風向画面は終了対象です。
このフォルダーの実行パスと `.edge-bousai` / `.edge-wind` プロファイルを確認して終了するため、
通常のEdgeや他のプロジェクトのPythonは対象にしません。すでに終了済みでも実行できます。
停止に失敗した場合はエラーを表示します。起動時と同じ権限で実行してください。

設定を変えたら、`stop_boards.bat` を実行してから `start_board.bat` を実行し直してください。
サーバーは画面に窓を出さずに動いているため、窓を閉じて止めることはできません。

`config.json` の書き方に誤りがあって読めないときは、`start_board.bat` は防災・交通情報の画面だけを既定の設定で開き、
理由を黒い窓に表示したまま止まります。風向・風速の画面は、有効かどうか読めないので開きません。
各サーバーも、読めなかった理由や起動できなかった理由をログに書きます。

注意点：

- 二重起動を防ぐ仕組みはまだありません。`start_board.bat` を続けて実行しないでください。
- 手動でサーバーを起動する場合、終了バッチから識別できるように、スクリプトを絶対パスで指定してください。
  相対パスだけで起動したプロセスは所属を確定できないので、`stop_boards.bat` では止まりません。
  元のターミナルで Ctrl+C するか、タスクマネージャーで終了してください。
- `start_board.bat` は応答しているサーバーをそのまま使います。手動で起動した古いサーバーが残っていると、
  更新したプログラムに入れ替わりません。

## 設定（config.json）

| 項目 | 内容 |
|---|---|
| `port` | 防災・交通情報画面のポート（初期値 `8765`） |
| `jr_lines` | 表示するJR東海の路線。JRサイトの表記で書きます。東海道線だけは `東海道線(豊橋～米原)` のように区間付きです。 |
| `subway_lines` | 表示する地下鉄路線。名城線と名港線は交通局のデータ上ひとつなので、1行で表示します。 |
| `meitetsu_lines` | 表示する名鉄の線区（初期値：名古屋本線、河和線、常滑線） |
| `quake_hold_hours` | 地震と長周期地震動を発生から何時間表示し続けるか（初期値24） |
| `enable_route23` | 国道23号欄の表示（保留中のため初期値 `false`） |
| `route23_notes` | 国道23号欄に常時表示するメモ（`enable_route23` が `true` のときだけ使います） |
| `google_maps_api_key` | Google Maps のAPIキー。入れると東海〜四日市の交通状況地図が表示されます。空欄なら地図は出ません。キーは表示ページに埋め込まれるので、`host` を `127.0.0.1` 以外にして他のPCから見られるようにする場合は、Google側でキーにHTTPリファラ制限を付けてください。 |
| `isewangan_east` / `isewangan_west` | 伊勢湾岸道の監視区間の両端 |
| `bousai_window_position` | 防災・交通情報画面の位置（初期値 `null`）。例 `[0, 0]` |
| `enable_wind` | 風向・風速画面を起動するか（初期値 `true`）。`false` にすると防災・交通情報画面だけを起動します。文字列の `"false"` ではなく、JSONの `false` を指定してください。次回の起動対象を選ぶ設定で、すでに動いているサーバーや画面は終了しません。単独起動の `python kaze_board.py` には適用しません。 |
| `wind_port` | 風向・風速画面のポート（初期値 `8766`）。`port` と別にします |
| `wind_interval` | 風向・風速の取得間隔（初期値 `60` 秒、最短15秒）。観測そのものは名古屋15分、四日市30分ごとです |
| `wind_caution_ms` | 風速の注意ライン（初期値 **`10` m/s**、依頼者指定）。グラフの固定軸に合わせ、0より大きく20以下で指定します |
| `wind_window_position` | 風向・風速画面の位置（初期値 `null`）。左のモニタなら例として `[-1920, 0]`。実機の配置に合わせて設定します |

## 防災・交通情報画面

### 発令条件の判定方法

| 画面の枠 | 条件 | 判定に使うデータ |
|---|---|---|
| 地震 | 愛知県（東部・西部）、三重県北部・中部で震度5弱以上 | 気象庁 地震情報（震度の細分区域 450/451/460/461） |
| 地震 | 同じ区域で長周期地震動階級3以上 | 気象庁 長周期地震動に関する観測情報 |
| 津波 | 伊勢・三河湾または愛知県外海に大津波警報（予想最大波3m超） | 気象庁 津波警報・注意報 |
| レベル5特別警報 | 愛知県全域、三重県北中部にレベル5の氾濫・大雨・土砂災害・高潮特別警報 | 気象庁 警報（2026年5月からの新しい形式） |
| 特別警報（気象） | 同じ区域に暴風・波浪・暴風雪・大雪の特別警報 | 同上 |
| 全国の地震 | 全国どこかで震度6弱以上 | 気象庁 地震情報 |

- 条件に当てはまった枠は赤くなり、画面上部の帯も赤に変わります。
- 津波警報・津波注意報と、レベル4の危険警報は、黄色の参考表示です。発令条件には数えません。
- データが取れていない枠には「データ取得遅延」と「判定できません」が出ます。この表示のときは、条件に当てはまっていないとは限りません。
- 警報の一部だけが取れていないときは「河川情報を確認中」のように出て、取れた範囲で判定します。

### 鉄道・道路の表示

- 鉄道欄は路線名と運行状態を優先します。長い詳細文は列ごとに3行→1行→非表示と調整し、
  詳細文の長さを理由に地下鉄などの文字を縮小したり、路線を「ほか○件」にまとめたりしません。
  詳細全文の常時表示は保証しません。表示路線を増やした場合は実機で収まりを確認してください。
- 取得できない状態が取得間隔の3倍（最短3分）続くと、平常だった路線は灰色の「判定できません」に変わります。
  運転見合わせ・遅れなどの表示は、次に確認できるまでそのまま残します。
- 一度も取得できていない会社は、取得を試す前は「取得中」、失敗した後は「判定できません」と灰色で出します。
  見出しの右にも「取得できていません」と出ます。伊勢湾岸道の欄も同じです。

### 取得元と更新間隔

| 内容 | 取得元 | 間隔 |
|---|---|---|
| 地震・津波 | 気象庁 | 20秒 |
| 長周期地震動・警報 | 気象庁 | 60秒 |
| JR東海 在来線 | JR東海 運行情報 | 60秒 |
| 地下鉄 | 名古屋市交通局 | 60秒 |
| 名鉄 | 名鉄 運行情報ページ | 90秒 |

| 伊勢湾岸道 | NEXCO中日本 アイハイウェイ | 90秒 |

## 風向・風速画面

名古屋港高潮防波堤中央堤東端と四日市防波堤信号所の観測を表示します。
1920×1080のレイアウトを、縦横比を保って画面内に収めます。フォント・色は防災・交通情報画面と同じです。
`python kaze_board.py`（Windowsでは `py -3 kaze_board.py` も可）で単独起動もできます。

- 「風弱く」は正常な観測で、欠測とは区別します。風向は「なし」、風速は「風弱く」と落ち着いた色で出し、グラフに限り0として表示します。
- 6時間最大・平均は**数値のある観測のみ**が対象です。「風弱く」と欠測を除外し、平均欄に数値観測件数／予定件数を表示します。全件が非数値なら統計は「—」です。最大瞬間風速ではありません。
- 欠測・観測間隔を超える空白は線を途切れさせます。四日市は30分値のまま表示します。
- 風配図の母数は風向と数値風速が揃った観測だけです。`kaze_history.json` に24時間分を保存し、再起動でも引き継ぎます。実際の集計期間は図の左上に「過去24時間の分布」のように出します。外周15%を超える方位は外周で止め、△を添えます。
- 風配図には、過去6時間に出た風向を1方向1本の薄い線で重ねます。「風弱く」などで今の矢印が無いときは、線をすべて同じ薄さにして、今の風向の針に見えないようにします。
- 名古屋は20分超・四日市は35分超で「取得再試行中」、それぞれ35分超・65分超で「判定できません」になります。
  「取得再試行中」は観測時刻の横に琥珀色で出します。「判定できません」は風速の右に破線の札で出し、古い数値は灰色で残して、風配図とグラフを薄くします。
- 通信に失敗しても前回値を保持し、観測時刻からの経過表示を続けます。サーバーから1分以上応答がないときは「通信断」を表示します。
- 現在の風速が注意ライン以上のときは、数字、パネルの縁、「注意ライン以上」の札が琥珀色になります。6時間最大風速が注意ライン以上なら、そのタイルも琥珀色です。古い値のときは琥珀色にしません。
- グラフの縦軸は0〜20 m/s固定で、20超は上端に印と最大値を表示します。注意ラインより上の部分は琥珀色で塗り、超えた観測が無いうちは注意ラインの破線を薄く出します。
- ノットは元の風速が整数のため、「約8 kt」のように整数で出します。数字は桁の幅をそろえ、値が変わっても単位の位置が動きません。
- 防災・交通情報画面と同じく、6時間ごとにページを読み込み直します。
- 焼き付き対策として、画面全体を10分ごとに数pxずつ動かします。表示確認モードでは動かしません。夜間に暗くする機能はありません。

データ源： [名古屋](https://www6.kaiho.mlit.go.jp/nagoyako/kisyou/nagoyako_bw.html)、
[四日市](https://www6.kaiho.mlit.go.jp/04kanku/yokkaichi/yokkaichiko_bkw_lt/kisyou/index.html)。
2026-09-16の実HTMLで両局25行、名古屋の風向・風速が空欄の欠測行、`風弱く`、単位のspan要素を確認。
四日市の共通配下への参照はグラフGIFのみで、両局の履歴を取得できる共通JSONは確認できなかったためHTML表を使用しています。
「風弱く」の数値閾値や個々の観測の平均時間は未確認で、独自に推定していません。
風力の換算は[気象庁の風力階級表](https://www.jma.go.jp/jma/kishou/know/yougo_hp/kaze.html)に基づきます。

## 分かっている制約

- **国道23号**：保留中です。取得処理は残してあり、`enable_route23` を `true` にすると名古屋国道事務所の規制・緊急情報が出ます（事故・渋滞の即時情報は含みません）。
- **名鉄の線区別判定**：「路線」欄の線区名で判定し、「理由」の先頭の線区名で、その線区で起きた事由か他線区からの波及かを分けて表示します。波及のときは「三河線 人身事故の影響」のように1行で出し、発生場所は下に1回だけ出します。
- **名鉄・あおなみ線**：データ形式がなくページの文章から読み取っています。サイトのデザインが変わると取れなくなることがあります。そのときはフッターに「取得できていません」と出ます。
- **夜間の表示**：各社のサイトやデータが出している内容に合わせます。JR・地下鉄・あおなみ線は夜間も「平常運転」を出しているのでそのまま表示します。名鉄は0:31〜4:59に「提供時間外」になるので「情報提供時間外」と表示します（異常情報が残っていればそちらを表示）。JRのサイトがメンテナンスで提供を止めているときは「情報提供停止中」と出します。
- **東海道新幹線**は対象外です。
- **伊勢湾岸道の渋滞**：「名港中央IC付近を先頭に 5km」「通過 25分（湾岸弥富IC→名港中央IC間）」の形で出ます。NEXCO中日本が配信しているのは渋滞の先頭位置・長さ・通過時間で、渋滞の末尾がどのICかは配信されていません。
- 各社サイトの非公式な利用です。仕様変更で動かなくなった場合は、該当の取得処理（`src_○○` 関数）の修正が必要です。

## 開発時の確認

```
python -m unittest -v test_bousai_board test_kaze_board test_launch_boards test_stop_boards test_board_layout
```

- `test_bousai_board`：発令条件の判定（地震・津波・警報・河川）と、鉄道各社の読み取り。ネットワークは使いません。
- `test_kaze_board`：風向・風速の観測の意味、鮮度、履歴。
- `test_launch_boards` / `test_stop_boards`：起動対象の選択と、終了対象の見分け（終了のテストはWindows専用）。
- `test_board_layout`：開発環境の Playwright と Edge で画面を確認します。1920×1080・1280×720の通常／警報時に、長い詳細文でも全7路線の状態と文字サイズが保たれること、取れていないデータを平常として見せないことを確かめます。

実データの確認は、取得処理を単体で呼んで行えます。

```
python -c "import bousai_board as b; print(b.src_jr())"
python -c "import kaze_board as k; print(k.src_nagoya())"
```
